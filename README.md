# Conversor de YouTube a MP3 (uso local)

## Requisitos
1. Node.js 18+
2. yt-dlp  (https://github.com/yt-dlp/yt-dlp)
3. ffmpeg  (https://ffmpeg.org)

Ambos deben estar en el PATH (prueba `yt-dlp --version` y `ffmpeg -version`).

## Uso
```
npm install
npm start
```
Abre http://localhost:3000, pega uno o varios enlaces (uno por línea) y pulsa "Convertir".

Úsalo solo con contenido propio, con licencia libre o que tengas permiso de descargar.
